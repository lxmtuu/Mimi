# Bundled Be Vietnam Pro fonts

Mimi bundles five unmodified upright static TrueType faces from the
[Be Vietnam Pro project](https://github.com/bettergui/BeVietnamPro):

| File | Weight | SHA-256 |
| --- | ---: | --- |
| `BeVietnamPro-Regular.ttf` | 400 | `cd1ef6e9d7db28ad5cdb88a65ccbe693870e60d340b791f349d248342b4fe4c3` |
| `BeVietnamPro-Medium.ttf` | 500 | `b60832bfa0fcd015158112c64d7e3fdad3b0c6287d1823f85a3103636e845268` |
| `BeVietnamPro-SemiBold.ttf` | 600 | `bd8e27eb02720b9d91e59e4f10a90878643219f25ce6a8d9a4f06a8a88d3bb71` |
| `BeVietnamPro-Bold.ttf` | 700 | `7f738fe5c43c8872807b20e2d30d42163618de8a4daf7f48a939adac32c16847` |
| `BeVietnamPro-ExtraBold.ttf` | 800 | `44dbfa01553d227bec76ba6446c5618870a76a4a3297f41630dde859d0650d02` |

The files were copied from upstream commit
`804e62d81abbbcdcce5686069c69b41b8c245192`, under `fonts/ttf/`.
Google Fonts' Be Vietnam Pro metadata identifies the designers as
Lâm Bảo, Tony Le, and ViệtAnh Nguyễn and records the same upstream commit.

Only the upright 400–800 faces used by Mimi's interface are bundled; italic
and display extremes are omitted to limit application size. The supplied
`OFL.txt` is the SIL Open Font License 1.1 text from the same upstream
commit and must remain with the font files. The font files have not been
modified.
